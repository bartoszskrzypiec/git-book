Dodatek A / Głębiej

Ściągawka: co ta komenda robi z grafem

Wszystkie komendy z książki na jednej stronie, opisane nie tym, jak się je wpisuje, ale tym, co przestawiają w grafie.

Zasada porządkowania

Nie po nazwie, tylko po skutku

Ściągawki zwykle porządkują komendy alfabetycznie albo tematycznie. Ta jest ułożona według tego, co komenda robi z grafem — bo to jest jedyny podział, z którego coś wynika. Trzy grupy, a w każdej odpowiedź na inne pytanie.

GrupaCo robiCzy da się cofnąć
przesuwa wskaźnikzmienia wartość refa albo HEADtak — poprzednia wartość jest w reflogu
buduje obiektytworzy nowe commity, drzewa, blob-ytak — stare obiekty zostają
rozmawia z serweremprzesyła obiekty, prosi o zmianę refazależy — jedyna grupa widoczna dla innych

Czwartej grupy nie ma. Wszystko, co robi git, mieści się w tych trzech.

Grupa I

Przesuwa wskaźnik

KomendaCo robi z grafem
git switch <galaz>przestawia HEAD na inną gałąź i układa pliki wg jej migawki
git switch -c <nazwa>tworzy nowy ref w bieżącym miejscu i przypina do niego HEAD
git switch --detach <sha>przestawia HEAD wprost na commit, z pominięciem gałęzi
git branch <nazwa>tworzy ref, nie rusza HEAD
git branch -d <nazwa>usuwa ref; commity zostają
git reset --soft <cel>przesuwa gałąź, zostawia index i pliki
git reset <cel>przesuwa gałąź i czyści index; pliki zostają
git reset --hard <cel>przesuwa gałąź, index i pliki — jedyna komenda z tej grupy, która potrafi coś stracić
git restore <plik>nie rusza żadnego refa; nadpisuje plik treścią z indeksu
git restore --staged <plik>wyjmuje plik z indeksu, nie rusza dysku
git tag <nazwa>tworzy ref, który z założenia się nie przesuwa

Cała grupa jest odwracalna, bo poprzednie wartości refów zapisuje reflog (Rozdział 18).

Grupa II

Buduje obiekty

KomendaCo robi z grafem
git add <plik>zapisuje treść pliku jako blob i wpisuje go do indeksu
git add -pto samo, ale wybranymi fragmentami
git commitbuduje drzewo z indeksu i commit wskazujący na HEAD; przesuwa gałąź
git commit --amendbuduje nowy commit z tym samym rodzicem; stary zostaje bez refa
git merge <galaz>przewija ref albo buduje commit z dwojgiem rodziców
git rebase <baza>buduje kopie Twoich commitów na nowej podstawie
git rebase -i <baza>to samo, według listy poleceń
git cherry-pick <sha>buduje kopię wskazanego commita na bieżącym szczycie
git revert <sha>buduje commit z odwrotną zmianą; nic nie przepisuje
git stashbuduje commity poza gałęzią i przywraca czysty katalog

Wszystko z tej grupy tylko dokłada. Commity „znikają” wyłącznie dlatego, że przestaje na nie wskazywać ref.

Grupa III

Rozmawia z serwerem

KomendaCo robi
git fetchpobiera obiekty i przestawia refy origin/*; Twoje gałęzie stoją
git fetch --prunedodatkowo usuwa refy zdalne, którym nic już nie odpowiada
git pullfetch plus scalenie — dwie operacje pod jedną nazwą
git pushwysyła obiekty i prosi o przesunięcie refa; wymaga fast-forward
git push -u origin <galaz>to samo plus zapisanie upstreamu w lokalnej konfiguracji
git push --force-with-leaseustawia ref niezależnie od pokrewieństwa, ale tylko jeśli po drugiej stronie jest to, czego się spodziewasz
git push --delete <galaz>usuwa ref po stronie serwera
git clone <url>tworzy repozytorium, pobiera obiekty i ustawia origin

Jedyna grupa, w której skutki widzą inni. Stąd cała ostrożność z Rozdziału 17.

Grupa IV, której nie ma

Komendy, które tylko patrzą

Osobno warto wymienić te, które nie zmieniają niczego. Można je uruchamiać zawsze, także w sytuacji, której się nie rozumie — i właśnie od nich warto zaczynać każdą diagnozę.

KomendaNa co odpowiada
git status -sbgdzie jestem, co mam w indeksie, o ile jestem do przodu i do tyłu
git log --oneline --graph --alljak wygląda graf i gdzie są gałęzie
git log --oneline A..Bco ma B ponad A
git diff / git diff --stagedkatalog kontra index / index kontra HEAD
git reflogco robiłem ostatnio i gdzie bywał HEAD
git show <sha>co zawiera ten commit
git cat-file -p <sha>surowa treść obiektu
git config --list --show-originjakie ustawienia obowiązują i z których plików pochodzą
git merge-base A Bgdzie te dwie linie się rozeszły

Dziewięć komend, żadna niczego nie psuje. To jest zestaw, który warto znać na pamięć.
